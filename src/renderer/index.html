Quick Tunnel limitations

  • The public URL (*.trycloudflare.com) is assigned randomly by Cloudflare and changes each time. You cannot choose its name or extension.
  • The public port is always HTTPS 443 and cannot be changed. Only the local port above is configurable.
  • Quick Tunnels carry HTTP/HTTPS websites only, not arbitrary TCP services.
  • Anyone with the URL can view the selected folder. This admin panel is never published.
